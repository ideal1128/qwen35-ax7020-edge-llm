# 验收摘要

## 一、功能项

| 项目 | 结果 | 依据 |
|---|---|---|
| 模型加载与完整前向 | 通过 | 24 层全部执行，输出连贯 |
| 多轮对话上下文 | 通过 | 上下文累加、`/clear` 正常复位 |
| 分词器正确性 | 通过 | `tb_tokenizer` 与 Python 参考逐 token 一致 |
| 输出完整性 | 通过 | 自然 `<|im_end|>` 停止，无硬截断 |
| 思考模式开关 | 通过 | `/think on|off|show|hide` 均生效，模板字节精确 |
| 采样 / 贪心双模式 | 通过 | top-k / top-p / 温度可调；`--greedy` 快路径 |
| 掉电重启自恢复 | 通过 | 重启后自动运行验收脚本并记 `status=PASS` |

## 二、性能项

| 指标 | 实测 | 说明 |
|---|---|---|
| 贪心解码 | 670.7 ms/token（1.491 tok/s） | 12 次连续前向稳定 |
| 默认采样 | 850.0 ms/token（1.176 tok/s） | top-k 40 / top-p 0.9 / T=0.7 |
| 纯 Python 基线 | 11,889 ms/token | 加速比 17.7× |
| 每 token 访存 | 681.1 MB | 已逼近实测带宽墙 |

## 三、硬件项

| 项目 | 实测 |
|---|---|
| DDR3 读带宽墙 | 1270.8 MB/s |
| NEON 指令发射上限 | 1220 MB/s |
| PL 侧 AXI 吞吐 | 1178 MB/s（理论峰值 74%） |
| Block Design 时序 | WNS **+0.018 ns**，0 条失败路径 |
| PL 实际运行时钟 | 100 MHz（由 `ps7_init` 设定） |
